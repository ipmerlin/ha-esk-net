# ЕСК — личный кабинет для Home Assistant

Неофициальная интеграция личного кабинета [**https://lk.esknet.net**](https://lk.esknet.net)

## Возможности

* Настройка логина и пароля через интерфейс HA, проверка входа перед добавлением.
* Баланс, дни до блокировки, тариф, стоимость тарифа в месяц и лицевой счёт.
* Полная стоимость в месяц с учётом всех услуг, скидок, акций и льгот — непосредственно из ЛК.
* Активированные услуги: количество в состоянии датчика, названия и месячные цены в атрибуте `services`.
* Несколько аккаунтов, отдельные cookie-сессии, защита от повторного добавления одного счёта.
* Обновление каждые 4 часа; в параметрах можно выбрать от 30 до 1440 минут.
* Повторный ввод учётных данных при отказе авторизации.
* При недоступности сайта сущности становятся недоступны; отсутствующие дополнительные поля получают `unknown`, а не выдуманный ноль.
* Русский и английский интерфейс; диагностический файл без учётных данных и финансовых значений.

Минимальная целевая версия: **Home Assistant 2025.12**. Интеграция читает HTML, поскольку в исходном скрипте нет документированного API. Изменения сайта могут потребовать обновления парсера. Операции оплаты, смены тарифа и обещанного платежа не реализованы.

## Установка через HACS

Репозиторий: [ipmerlin/ha-esk-net](https://github.com/ipmerlin/ha-esk-net).

**1. Откройте репозиторий в HACS и скачайте интеграцию:**

[![Открыть в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ipmerlin&repository=ha-esk-net&category=integration)

**2. Перезапустите Home Assistant, затем добавьте ЕСК:**

[![Добавить интеграцию в Home Assistant](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=esk_net)

Кнопки используют [My Home Assistant](https://www.home-assistant.io/integrations/my/). При первом переходе укажите адрес вашего HA. Для первой кнопки HACS должен быть установлен; вторую используйте после скачивания интеграции и перезапуска HA.

Можно установить вручную через интерфейс HACS:

1. В HACS откройте меню → **Пользовательские репозитории**.
2. Добавьте `https://github.com/ipmerlin/ha-esk-net`, тип **Интеграция**.
3. Найдите **ЕСК — личный кабинет** и скачайте.
4. Перезапустите Home Assistant.
5. **Настройки → Устройства и службы → Добавить интеграцию → ЕСК**.
6. Введите логин и пароль личного кабинета.

Автоматическое появление в общем каталоге HACS — отдельная процедура. Для установки из пользовательского репозитория она не требуется.

## Ручная установка

Скопируйте каталог `custom_components/esk_net` в `/config/custom_components/esk_net` на сервере HA, перезапустите HA и добавьте интеграцию через интерфейс. Если используете архив [esk_net-0.1.2.zip](https://github.com/ipmerlin/ha-esk-net/releases/download/v0.1.2/esk_net-0.1.2.zip), распакуйте его в `/config`: внутри уже есть `custom_components/esk_net`.

## Обновление и диагностика

Параметры интеграции меняют интервал опроса. Для внеочередного чтения вызовите действие `homeassistant.update_entity` для любого её датчика — координатор обновит все показания за один цикл опроса.

При каждом обновлении интеграция читает главную страницу и страницу информации о тарифе. «Стоимость тарифа в месяц» показывает цену самого тарифа, а «Полная стоимость в месяц» — итоговую сумму из ЛК. Атрибут `services` датчика «Активированные услуги» содержит список объектов с полями `name` и `monthly_price`; валюта — `RUB`. Если страница услуг недоступна, эти данные становятся неизвестными, а сведения с главной страницы продолжают обновляться.

`cannot_connect` означает сетевую ошибку/HTTP-ошибку, `invalid_auth` — отказ авторизации или возврат формы входа, `cannot_parse` — неожиданный HTML либо незавершённую проверку сайта. Изменение вёрстки не трактуется автоматически как неверный пароль.
