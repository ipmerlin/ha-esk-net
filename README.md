# ЕСК — личный кабинет для Home Assistant

Неофициальная интеграция личного кабинета [**https://lk.esknet.net**](https://lk.esknet.net)

Баланс, тариф, подключённые услуги и QR для оплаты через СБП в Home Assistant. Поддерживается несколько лицевых счетов. Требуется **Home Assistant 2025.12 или новее**.

## Установка через HACS

**1. Откройте репозиторий в HACS и скачайте интеграцию:**

[![Открыть в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ipmerlin&repository=ha-esk-net&category=integration)

**2. Перезапустите Home Assistant и добавьте ЕСК:**

[![Добавить интеграцию в Home Assistant](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=esk_net)

**3. Введите логин и пароль личного кабинета.**

Без кнопок: добавьте `https://github.com/ipmerlin/ha-esk-net` в **HACS → Пользовательские репозитории**, тип **Интеграция**. Скачайте ЕСК, перезапустите HA и откройте **Настройки → Устройства и службы → Добавить интеграцию → ЕСК**.

## Ручная установка

Скачайте архив `esk_net-*.zip` из [последнего релиза](https://github.com/ipmerlin/ha-esk-net/releases/latest) и распакуйте его в `/config`: должен появиться каталог `/config/custom_components/esk_net`. Перезапустите HA и добавьте ЕСК через **Настройки → Устройства и службы → Добавить интеграцию**.

## Сенсоры

| Сенсор | Что показывает |
| --- | --- |
| Баланс | Текущий остаток на лицевом счёте, ₽. |
| Дней до блокировки | Число дней до блокировки, если оно указано в ЛК. |
| Лицевой счёт | Номер лицевого счёта. |
| Тариф | Название текущего тарифа. |
| Стоимость тарифа в месяц | Месячная цена самого тарифа, ₽. |
| Полная стоимость в месяц | Итоговая месячная стоимость всех услуг с учётом скидок, акций и льгот из ЛК, ₽. |
| Активированные услуги | Количество подключённых услуг. В атрибуте `services` — их названия (`name`) и месячные цены (`monthly_price`). |
| Отдельный сенсор каждой услуги | Название услуги из ЛК и её стоимость в месяц, ₽. Создаётся автоматически. |

Если данных нет в ЛК, сенсор показывает **«Неизвестно»**.

## Оплата через СБП

1. В поле **«Сумма пополнения СБП»** укажите целую сумму в рублях (от 10 до 100 000).
2. Нажмите **«Получить QR СБП»**.
3. Откройте **«QR для оплаты СБП»**, отсканируйте его банковским приложением и подтвердите оплату в банке. Изображение QR можно добавить на панель HA.

При изменении суммы или перезапуске HA получите QR заново. Баланс обновится при следующем опросе; статус оплаты QR интеграция не отслеживает.

## Обновление данных

По умолчанию — каждые **4 часа**. В параметрах интеграции можно выбрать интервал от **30 минут до 24 часов**. Для обновления вручную вызовите действие `homeassistant.update_entity` для любого сенсора ЕСК.
